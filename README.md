# Atlas de Microbiología · Grupo GERMEN

Atlas interactivo de microbiología del grupo GERMEN (Universidad de Antioquia): modelos 3D de bacterias, hongos, parásitos y virus, estructura de la pared celular al hacer zoom, mecanismos de patogenicidad y de resistencia animados.

**Ver en línea:** https://julianepiudea.github.io/atlas-microbiologia-germen/

- `index.html` — página (generada a partir de `atlas-micro.html`).
- `js/` — datos de los organismos, constructores 3D (Three.js), paredes celulares y animaciones de mecanismos.

Fuentes de estructura viral: ViralZone (SIB).
